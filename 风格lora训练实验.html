四类训练任务与模型总览

魔搭 AIGC 专区「模型训练」页顶部有四个任务标签：图像模型 图像编辑模型 视频模型 音乐模型。 先选对任务类型，再选底模——这一步决定后面整套数据组织和参数逻辑。

任务类型训练数据形态典型用途你的场景
图像模型单张图片 + 描述 txt（也可选图片组）人物、画风、产品、IP 等"文生图"概念—
图像编辑模型 ✅图片组：start + end + 指令 txt"把这张图变成某风格 / 换发型 / 换背景"等图生图编辑就是这类
视频模型5–10 秒短视频片段（可选首尾帧）特定运动、转场、视频风格—
音乐模型音频素材音色、曲风—
为什么你的场景必须选「图像编辑模型」？ 你有 17 组「原始照片 → 风格化结果」的配对，目标是让模型学会"把输入图编辑成某种风格"。 这类成对编辑映射只有图片编辑模型（如 Qwen-Image-Edit）支持； 选成图像模型的话，平台会把 start/end 当成独立图片，学不到"编辑前后"的对应关系。

数据格式总览（start / end / txt）

平台要求压缩包内是若干"组"，每组由 起始图 + 目标图 + 一个同名 txt 构成。命名规则如下：

N_start.jpg
编辑前 · 原始照片
+
N_end.jpg
编辑后 · 风格化结果
+
N.txt
编辑指令文本

其中 N 是组的编号（1、2、3…），三个文件必须同号对应。以你的 clay-style_ready 为例：

clay-style_ready/
├── 1_start.jpg   1_end.jpg   1.txt
├── 2_start.jpg   2_end.jpg   2.txt
│   ...
└── 17_start.jpg  17_end.jpg  17.txt
✅ 你已经做好的部分 上一轮整理出的三个 _ready 文件夹，每个都是 17 组、编号连续、图片为真 JPEG，格式层面完全符合要求。
⚠️ 数量与格式红线 每个压缩包最多 300 组（你有 17 组，远低于上限）；平台界面同时标注"数量 10–100 张"为推荐训练区间。 只认 .jpg 图片 + .txt 文本，.DS_Store 等杂项会被忽略。图片宽高 512–2048，特征明显、角度丰富、不模糊、无水印。

注：Qwen Image Edit 也支持多张参考图（N_start2.jpg、N_start3.jpg 等），你的场景是单张输入，一组 start/end 即可。平台右侧的「上传单图 / 上传图片组」按钮，编辑训练要用「上传图片组」。

3

关键一步：把标注改成"编辑指令"

🔥 最容易踩的坑（务必看） 你上一轮在 N.txt 里写的是静态风格描述，例如 "A vivid and captivating scene, 3D claymation style, ..."。 但图片编辑模型训练时，txt 应描述「把 start 编辑成 end 这个动作」，而非对某张图的静态说明。 两者方向不同，直接用静态描述会削弱模型对"编辑操作"的学习。

正确的指令长什么样？

风格建议的 txt 编辑指令（每组都写同一条即可）
粘土定格动画Transform the input photo into a vivid 3D claymation style, cute clay illustration with detailed clay texture and subtle fingerprints, soft studio lighting, plasticine aesthetic, handcrafted details, vibrant colors, stop-motion film still, octane render. Keep the original hairstyle and composition.
梵高厚涂油画Transform the input photo into the style of Vincent van Gogh, impasto oil painting with thick paint texture, visible coarse brushstrokes, swirling patterns, vibrant yellow and deep blue palette, dramatic organic curves, highly expressive, heavily textured canvas. Keep the original hairstyle and composition.
温馨手绘彩铅Transform the input photo into a cozy hand-drawn illustration style, watercolor and colored pencil texture, soft pencil sketch outlines, warm and gentle tones, whimsical fairy tale aesthetic, subtle paper grain background, highly detailed, cute and heartwarming. Keep the original hairstyle and composition.

指令三要点：① 说清要做的改变（转成什么风格）；② 说清要保留什么（发型、构图）；③ 全数据集措辞一致。

要不要改？两种做法
方案 A（推荐）：上传前用下面脚本把三个 _ready 文件夹的 txt 批量替换为编辑指令。
方案 B（省事）：让平台用「智能打标 / JoyCaption」自动重新打标，但描述由模型反推、无法精确控制措辞。

批量替换 txt 的脚本（方案 A）

# 在终端执行，把三个 _ready 文件夹里的 N.txt 改写为对应风格的编辑指令
python3 - <<'PY'
import os
base = "/path/to/train_data"
prompts = {
 "clay-style_ready": "Transform the input photo into a vivid 3D claymation style, cute clay illustration with detailed clay texture and subtle fingerprints, soft studio lighting, plasticine aesthetic, handcrafted details, vibrant colors, stop-motion film still, octane render. Keep the original hairstyle and composition.",
 "VanGogh-style_ready": "Transform the input photo into the style of Vincent van Gogh, impasto oil painting with thick paint texture, visible coarse brushstrokes, swirling patterns, vibrant yellow and deep blue palette, dramatic organic curves, highly expressive, heavily textured canvas. Keep the original hairstyle and composition.",
 "illustration-style_ready": "Transform the input photo into a cozy hand-drawn illustration style, watercolor and colored pencil texture, soft pencil sketch outlines, warm and gentle tones, whimsical fairy tale aesthetic, subtle paper grain background, highly detailed, cute and heartwarming. Keep the original hairstyle and composition.",
}
for folder, text in prompts.items():
    d = os.path.join(base, folder)
    for f in os.listdir(d):
        if f.endswith(".txt"):
            with open(os.path.join(d, f), "w", encoding="utf-8") as fh:
                fh.write(text)
    print(folder, "done")
PY

打包成平台可上传的 ZIP

每个风格单独打一个 ZIP（三个风格训三个 LoRA）。关键点：ZIP 里直接就是 1_start.jpg / 1_end.jpg / 1.txt，不要再套一层文件夹。

# 在 train_data 目录下执行，生成三个干净的 zip
cd "/path/to/train_data"
for d in clay-style_ready VanGogh-style_ready illustration-style_ready; do
  (cd "$d" && zip -q -r "../${d}.zip" . -x ".DS_Store")
done
ls -lh *_ready.zip
打包检查解压后第一层就要看到 1_start.jpg，而不是 clay-style_ready/1_start.jpg。 macOS 访达右键压缩会带上 __MACOSX 目录，建议用上面的命令行方式。

专业参数深度解读

点「专业参数」会弹出配置面板，左侧共 7 个选项卡：样图设置、保存设置、学习率&优化器、数据集设置、网络设置、高级设置（面板可滚动）。下面按平台界面中的默认值逐项讲清楚"是什么 / 怎么调"。

7.1 面板默认值速查

选项卡参数默认值作用
保存设置LoRA 保存精度 Save precisionbf16权重文件的数值精度
学习率&优化器总学习率 Learning rate0.0001每步参数更新幅度
学习率&优化器优化器 OptimizerAdamW参数更新的算法

提示界面上分辨率旁有一行小字："增大分辨率会影响训练速度，请酌情设置总步数"。 意思是分辨率与训练步数是联动的——图越大越慢，别只调分辨率不加步数。

7.2 优化器 Optimizer：怎么选？

优化器决定"如何根据损失更新权重"，直接影响收敛速度、显存占用和最终质量。常见选项对比：

优化器特点显存建议学习率适用场景
AdamW（默认）经典稳定、通用性好、质量上限高高1e-4默认首选，数据质量高、显存充足时
AdamW8bit8 位量化，显存降约一半、速度更快，质量损失极小中1e-4显存吃紧时的首选替代
Adafactor内存效率高，会自动调整学习率（手动设的学习率常被忽略）低交由自动大模型 / 显存很紧
Lion新型优化器，速度快、显存低，但稳定性略逊、结果可能波动很低1e-4 量级探索性训练、低显存环境
DAdapt / Prodigy自动学习率，通常填 1.0 左右；注意不能与 LoRA+ 同用中≈1.0不想手调学习率时
SGD Nesterov传统动量法，精度可但收敛慢低需单独试特殊需求
给你的一句话建议先用默认 AdamW + 1e-4 跑通；报显存不足就换 AdamW8bit； 想少调参可试 DAdapt（学习率填 1.0）。别一上来就用 Lion 等实验性选项。

7.3 学习率 Learning rate：最重要的单个超参

它决定每次更新"迈多大步"。太大→训练震荡、loss 爆炸甚至模型崩塌；太小→学不动、欠拟合。

场景建议学习率说明
默认值 / 大多数情况1e-4（0.0001）稳妥起点
风格 LoRA（你的场景）5e-5 ~ 1e-4风格特征相对统一，可偏低一点更稳
角色 / 精细特征 LoRA1e-4 ~ 2e-4需要更强学习来记住细节
数据量很少（<20 张）偏低 + 少步数配合低 rank，防止过拟合

学习率调度器（LR Scheduler）决定学习率随时间怎么变，通常在"高级设置"里：

调度器行为何时用
constant全程不变前期快速收敛
cosine按余弦曲线衰减后期精细收敛、收尾
constant_with_warmup先线性热身再恒定训练初期不稳定时
cosine_with_restarts余弦衰减伴随重启跳出局部最优，进阶

常用策略：前 5 轮 constant、后 5–10 轮 cosine；Warmup（热身）一般取总步数的 5%–10%，让模型先"热身"再全速学习。 若面板提供"文本编码器学习率"，通常设得比主学习率更低（如 1e-5 ~ 5e-5），避免破坏文本理解能力。

7.4 网络大小 Network rank dim：LoRA 的"记忆容量"

Rank 决定 LoRA 能存多少信息。越大可塑性越强、能记更复杂特征，但文件更大、更易过拟合，也需要更多数据支撑。

Rank适合场景大致文件体积
8–16简单风格、轻量特征（默认 16 够用）约 5–40 MB
16–32通用推荐，质量与体积平衡约 15–40 MB
32–64复杂角色、精细细节约 40–80 MB
64+特殊需求，需大量数据支撑80 MB 以上

经验法则：数据越少，rank 越低。你每组风格只有 17 张，建议 rank 从默认 16 起步，最多到 32；直接上 64 容易过拟合（只会照搬训练图）。

Network Alpha（若面板提供） Alpha 是缩放因子，实际生效强度约为 alpha / rank。常见设成 alpha = rank（强度 1，不额外缩放） 或 alpha = rank/2（强度 0.5，更温和）。改了 alpha 等于变相改了学习率强度，调它时要留意。

7.5 分辨率 Resolution 与保存精度

  • 分辨率：默认 1024×1024，平台要求宽高在 512–2048。风格统一、主体清晰即可，不必盲目调高；调高会显著变慢并需要更多步数。
  • 保存精度 bf16：动态范围大、不易数值溢出，是当前默认且推荐值。fp16 精度更高但范围小、极端情况易溢出；fp32 最稳但文件大。
  • 样图设置：配置训练过程中生成预览图的提示词、采样步数、种子等，用来直观判断各 Checkpoint 的效果，建议填一条与你指令一致的样图提示。
  • 保存设置：除精度外，通常还有"每 N 轮保存一个 LoRA"——保存点越密越方便挑最佳版本，代价是占更多存储。
  • 高级设置：可能包含梯度累积、噪声偏移（noise offset）、混合精度、随机种子等进阶项；新手保持默认即可。

7.6 一套可直接照抄的配置（你的风格任务）

任务类型      : 图像编辑模型

10

常见问题与踩坑清单

现象原因 / 处理
训练出来"没学会风格"① txt 用了静态描述而非编辑指令 → 回到第 3 步改写；② 步数太少 → 提到 6000 左右；③ 样本质量参差 → 保证风格一致、无水印
只会照搬训练图（过拟合）降低 rank（回到 16）、减少步数/单张次数、增加样本多样性
训练震荡 / loss 爆炸学习率过大 → 降到 5e-5；开启 warmup；检查数据标注是否混乱
报显存不足优化器从 AdamW 换 AdamW8bit；降低分辨率；减小 batch（若可调）
图片被忽略 / 组数不对压缩包层级不对或含违规格式；解压第一层必须是 N_start.jpg / N_end.jpg / N.txt
选错模型（选成图像模型）回到"图像编辑模型"标签重选底模，数据按图片组重新上传
切换专业训练后数据不见了平台切换训练模式会清空已上传数据，需在新页面重新上传
任务超时终止点任务卡片右上角「重启」继续，不必从头提交

训练前 60 秒自检

  • 任务类型选的是图像编辑模型，底模为 Qwen Image Edit 2511 / Qwen-Image-2.1
  • 每个 ZIP ≤ 300 组，解压后文件在根目录层级，无杂项
  • 每组 N_start.jpg + N_end.jpg + N.txt 编号一致
  • txt 是"编辑指令"而非静态描述，且全数据集措辞统一
  • 学习率 1e-4、优化器 AdamW、rank 16、分辨率 1024、精度 bf16（默认值起步）
  • 已想好用免费训练还是专业训练（切换会清空数据）
