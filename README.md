# aitoolkit-colab

美图影像研究院（MT Lab）技术分享 **《从噪声到影像：图像与视频生成模型的技术演进》** 的配套资料库。讲义用 90 分钟梳理 2014—2026 年生成式 AI 的发展脉络，本仓库收录其中引用的论文原文与动手实验资料。

## 技术演进主线

讲义以技术演进为主线，配产业一线案例与可上手实验，核心可归纳为三次跃迁与一条主线：

- **图像**：GAN 的博弈 → 扩散的去噪 → DiT 的规模定律
- **视频**：逐帧拼接 → 时空 Patch 整体建模 → 原生音视频一体
- **主线**：架构统一（Transformer）＋ 条件统一（多模态）＋ 使用门槛持续下降

两个关键拐点：**2020 年**（DDPM 图像质量超越 GAN，研究全面转向扩散）与 **2024 年**（Sora 演示让视频生成「出圈」）。讲义目录：

| 时段 | 章节 | 要点 |
| --- | --- | --- |
| 00–10 分 | 开场 | 讲师、美图与 MT Lab；产业一线视角 |
| 10–35 分 | 图像生成 | GAN → 扩散 → DiT 两次跃迁，含互动讨论 |
| 35–40 分 | 休息与环境准备 | 预热实验台与 Colab Notebook |
| 40–60 分 | 视频生成 | 鬼畜年代 → Sora 时空 Patch → 量产元年与中国力量 |
| 60–72 分 | 边界与找茬 | 能力边界、AI 影像鉴别、分组找茬挑战 |
| 72–90 分 | 动手实验与总结 | 扩散去噪代码实操、三大核心旋钮 |

## 动手实验

讲义设计了三阶段闯关式实验：① 30 行 PyTorch 跑通加噪与去噪；② 拧动 Steps / CFG Scale / Seed 三大核心旋钮；③ 交互仿真 + 代码实操 + 现场「炸图」会诊。

本仓库另收录一组风格 LoRA 训练实验资料，可作为生成模型动手实践的补充：

- `实验归档/` — 风格 LoRA 训练的数据集与 HTML 操作教程
- `notebooks/` — `SliderTraining.ipynb`（Colab Notebook）
